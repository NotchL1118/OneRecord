# OneRecord 已确认的界面原型

确认日期：2026-10-10。本目录保留「团子陪伴」界面与 24 组浅色配色的设计参考，默认配色为香草布丁。

正式需求以仓库中的「OneRecord 页面与交互设计规格」及[首版功能规格](https://github.com/NotchL1118/OneRecord/issues/1)为准。技术约束见[技术选型记录](https://github.com/NotchL1118/OneRecord/issues/2)。

## 文件

- `approved-prototype.html`：可下载后用浏览器打开的独立演示页面。部分图标资源需要网络；无需启动服务或安装依赖。
- `approved-prototype.fragment.html`：用户确认的原始交互片段，适用于 Codex 可视化预览。
- `palette-catalog.json`：24 组配色、稳定编号、默认值与语义颜色的派生规则。

## 参考范围

从首页右上角头像进入「更多 → 外观与配色」切换主题；底部切换记录、日记、对话。日记条目、编辑、心情面板、聊天历史和引用均可点击。

这些代码只用于讨论页面结构、视觉层级与交互入口，不是 iOS 实现。日记、日期、录音、转写、AI 回复和服务商均为模拟。演示中的恢复方式不能代替正式 App 的持久化，计时器也不能代替后台录音。尚未完成权限、故障、无障碍、动态字体及真机适配的完整验证。

新聊天在原型中要求手选范围，并在发送后统一禁用范围和模型控件。这是原型简化：功能规格要求初始范围为「全部」，首条消息固定的是连接与模型；不能从演示代码推导额外的范围锁定要求。

最后预览过某个配色不等于修改默认值。新安装仍使用编号 05「香草布丁」，恢复已有选择时才使用用户保存的主题。

该快照保留在设计参考分支，不直接合入应用主线。后续原生开发按规格重写业务与页面。
